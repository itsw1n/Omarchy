# Setup screenshots

Screenshots of this desktop across configuration states. Add images to the
topic folder that matches what they show, then list them below.

Naming: `<state>-<detail>.png`, lowercase with hyphens, for example
`old-waybar.png` or `spectra.png`. Describe the configuration state rather than
the date so a replacement image keeps the same link.

## Bar

`bar/` — bar versions and comparisons, such as the old Waybar and the current
Spectra bar.

- [`old-waybar.png`](bar/old-waybar.png) — old Waybar with btop and files.

## Desktop

`desktop/` — desktop layout, wallpaper, gaps, borders and monitor arrangements.

- [`omarchy-menu.png`](desktop/omarchy-menu.png) — Omarchy menu on the desktop.

## Lock screen

`lock-screen/` — lock screen and screensaver captures.

- [`lockscreen.png`](lock-screen/lockscreen.png) — lock screen with the DEYMN logo.
- [`screensaver.png`](lock-screen/screensaver.png) — DEYMN ASCII screensaver.
